Aplicação web desenvolvida para organizar avaliações de fatores de riscos psicossociais no ambiente de trabalho.

**Principais recursos:**
- Questionário estruturado
- Avaliação por setores
- Geração de QR Code
- Visualização de resultados
- Geração de relatórios

- Interface responsiva

**Tecnologias:** React · TypeScript · Vite
